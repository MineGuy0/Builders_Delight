# 🛠️ Builder's Delight (Fabric 1.20.1)

**Builder’s Delight** is a feature-rich Fabric mod for Minecraft 1.20.1, packed with advanced building tools, custom blocks, powerful enchantments, and quality-of-life upgrades tailored for builders, redstoners, and survival engineers alike.

---

## ✨ Features

### 🔧 Custom Tools
- **Hammer**: Mines large configurable areas with optional Nudge control and Hammering enchantment.
- **Paxel & Reaper**: Hybrid tools with configurable behavior for multiple block types.
- **Life Weaver Sword**: Strikes with high true damage and custom death messages.
- **Cloak**: When equipped (armor or trinket), renders the player invisible from certain angles.

### 🧱 New Blocks
- **Steel Bulb Block**: Toggleable redstone lamp-like block with LIT state and proper model switching.
- **Multi-colored Lamps**: All 16 dyed variants, bright and aesthetic.
- **Steel Grates, Chiseled Steel, Cut Steel**: Industrial-style decorative blocks.

### 📘 Custom Enchantments
- **Hammering I–III**: Expands hammer mining radius.
- **Arthropedic Efficiency**: Boosts speed on organic blocks.
- **Extended Efficiency**: Efficiency up to level 10 with scaling formula.
- **Axing & Shoveling**: Add axe or shovel behavior to multi-tools.

### 💼 Armor & Effects
- **Stardust Armor**: High-tier fireproof armor with speed & HP bonuses when worn fully.
- **Cloak of Invisibility**: Works with trinkets mod to cloak the player in stealth.

### 🔨 Data-Driven + Client Features
- Keybinds for Nudge control (`Home`, `End`, `Del`, `PageDown`).
- Block outline previews for hammers.
- Data generators for recipes, models, loot tables, and tags.

---

## 🧰 Getting Started

### Prerequisites
- Minecraft **1.20.1**
- Fabric Loader + Fabric API
- [Trinkets API](https://modrinth.com/mod/trinkets) (for Cloak functionality)

### Installation
1. Download the `.jar` from [Releases](https://github.com/YOUR_USERNAME/builders-delight/releases).
2. Drop it into your `mods/` folder.
3. Launch Minecraft with Fabric 1.20.1.
